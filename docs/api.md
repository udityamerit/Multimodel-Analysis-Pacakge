## MultiModelClassifier

Trains many classifiers on one split and ranks them (Accuracy, Precision, Recall, F1, ROC-AUC).

```python
MultiModelClassifier(X: Union[pd.DataFrame, np.ndarray, NoneType] = None, y: Union[pd.Series, pd.DataFrame, np.ndarray, NoneType] = None, test_size: float = 0.3, scaled_data: bool = True, random_state: Optional[int] = 42, stratify: bool = True, n_jobs: Optional[int] = -1, verbose: bool = True, preprocess: bool = False, class_weight: Optional[str] = None)
```

### Run models

- **`run_all_models(custom_models: Optional[Dict[str, Any]] = None, random_state: Optional[int] = None, include: Optional[List[str]] = None, exclude: Optional[List[str]] = None) -> List[Tuple]`**  
  Runs every built-in model (optionally filtered with ``include`` / ``exclude``) plus ``custom_models``.
- **`run_model(name: str, random_state: Optional[int] = None, **params) -> Tuple`**  
  Runs ONE built-in model by key or display name, e.g. ``run_model('random_forest', n_estimators=300)``.
- **`tune_models(include: Optional[List[str]] = None, exclude: Optional[List[str]] = None, search: str = 'random', n_iter: int = 20, cv: Union[int, Any] = 5, scoring: Optional[str] = None, param_grids: Optional[Dict[str, Dict[str, List[Any]]]] = None, random_state: Optional[int] = None) -> List[Tuple]`**  
  Tunes hyper-parameters of the built-in models, then refits and evaluates each on the test split.
- **`cross_validate_models(cv: Union[int, Any] = 5, scoring: Union[str, List[str], NoneType] = None, include: Optional[List[str]] = None, exclude: Optional[List[str]] = None, custom_models: Optional[Dict[str, Any]] = None) -> pd.DataFrame`**  
  Cross-validates every model on the TRAINING split (the test split stays untouched).

### Results

- **`show_tabular_report(models: Optional[List[Tuple]] = None, return_df: bool = False, sort_by: str = 'Accuracy') -> Optional[pd.DataFrame]`**  
  Displays all model metrics in a clean tabular format and recommends the best model.
- **`get_summary(models: Optional[List[Tuple]] = None, save_prefix: Optional[str] = None, show_plot: bool = True)`**  
  Runs full reporting and visualization pipeline.
- **`get_model(name: str) -> Any`**  
  Returns the FITTED estimator for ``name`` (display name, as shown in the report).

### Predict on new data

- **`predict(X_new: Any, model: Optional[str] = None) -> np.ndarray`**  
  Predicts for NEW raw data with a fitted model (default: the best model of the last report).

### Explain

- **`feature_importance(model: Optional[str] = None, n_repeats: int = 10, scoring: Optional[str] = None, max_rows: int = 2000) -> pd.DataFrame`**  
  Permutation importance: how much the test score drops when one feature is shuffled.
- **`partial_dependence(feature: Union[str, int], model: Optional[str] = None, grid_points: int = 20, class_label: Any = None, max_rows: int = 500) -> pd.DataFrame`**  
  Average prediction as ONE feature sweeps over its range, all other columns left as they are.

### Plots

- **`plot_comparison(models: Optional[List[Tuple]] = None, save_path: Optional[str] = None, show_plot: bool = True, metric: str = 'F1 Score')`**  
  Plots all models ranked on one metric (default 'F1 Score'; or 'Accuracy', 'Precision', 'Recall', 'ROC AUC').
- **`plot_confusion_matrices(models: Optional[List[Tuple]] = None, save_path: Optional[str] = None, show_plot: bool = True)`**  
  Plots confusion matrices for all models with custom colormaps and class labels.
- **`plot_feature_importance(model: Optional[str] = None, top: int = 15, n_repeats: int = 10, scoring: Optional[str] = None, save_path: Optional[str] = None, show_plot: bool = True)`**  
  Horizontal bars of the permutation importance (most important feature on top, +/- 1 std as whiskers).
- **`plot_partial_dependence(features: Union[str, int, Sequence[Union[str, int]], NoneType] = None, model: Optional[str] = None, class_label: Any = None, grid_points: int = 20, save_path: Optional[str] = None, show_plot: bool = True)`**  
  One line per feature: how the average prediction moves as that feature changes.
- **`plot_roc_curves(models: Optional[List[Tuple]] = None, save_path: Optional[str] = None, show_plot: bool = True)`**  
  Plots ROC curves for all models in a single combined plot.

### Save and load

- **`save_report(df_or_filepath: Union[pd.DataFrame, str, NoneType] = None, filepath: Optional[str] = None) -> None`**  
  Saves tabular report to CSV/Excel/HTML/JSON.
- **`save_html_report(path: str = 'report.html', title: Optional[str] = None) -> str`**  
  Writes ONE self-contained HTML file: the results table, the plots and any warnings / failed models.
- **`save_model(path: str, model: Optional[str] = None) -> str`**  
  Saves a fitted model + its preprocessing to ``path`` (joblib). Reload with ``load_model(path)``.
- **`export_model(model: Optional[str] = None) -> multimodel_analysis.core.persistence.TrainedModel`**  
  Bundles a fitted model with its preprocessing into a :class:`TrainedModel` (default: the best one).

### Other

- **`evaluate_model(model: Any, X_test: Optional[Any] = None, y_true: Optional[np.ndarray] = None)`**  
  Evaluates a fitted classifier.

### Older one-model methods

Kept so existing code still works: `AdaBoost_model()`, `DecisionTree_model()`, `GradientBoosting_model()`, `KNN_model()`, `Logistic_model()`, `Naive_Bayes_model()`, `RandomForest_model()`, `Support_vector_model()`. Prefer `run_model('key')`.

## MultiModelClusterer

Groups rows without a target; ranks methods by Silhouette, Calinski-Harabasz, Davies-Bouldin (and ARI/NMI if you pass labels).

```python
MultiModelClusterer(X: Union[pd.DataFrame, np.ndarray, NoneType] = None, y: Union[pd.Series, np.ndarray, NoneType] = None, n_clusters: Union[int, str] = 3, scaled_data: bool = True, random_state: Optional[int] = 42, n_jobs: Optional[int] = -1, verbose: bool = True, preprocess: bool = False)
```

- **`run_all_models(custom_models: Optional[Dict[str, Any]] = None, random_state: Optional[int] = None, include: Optional[Any] = None, exclude: Optional[List[str]] = None, allow_large: bool = False) -> List[multimodel_analysis.unsupervised.clustering.ClusterResult]`**

## MultiModelAnomalyDetector

Flags unusual rows (1 = anomaly) with many detectors and measures how much they agree.

```python
MultiModelAnomalyDetector(X: Union[pd.DataFrame, np.ndarray, NoneType] = None, y: Union[pd.Series, np.ndarray, NoneType] = None, contamination: Optional[float] = None, scaled_data: bool = True, random_state: Optional[int] = 42, n_jobs: Optional[int] = -1, verbose: bool = True, preprocess: bool = False)
```

### Run models

- **`run_all_models(custom_models: Optional[Dict[str, Any]] = None, random_state: Optional[int] = None, include: Optional[Any] = None, exclude: Optional[List[str]] = None, allow_large: bool = False) -> List[multimodel_analysis.unsupervised.anomaly.AnomalyResult]`**  
  Runs every standard detector (``include='all'`` for all installed ones) plus ``custom_models``.
- **`run_model(name: str, random_state: Optional[int] = None, **params) -> multimodel_analysis.unsupervised.anomaly.AnomalyResult`**  
  Runs ONE built-in detector by key or display name, e.g. ``run_model('lof', n_neighbors=35)``.

### Results

- **`show_tabular_report(models: Optional[List[multimodel_analysis.unsupervised.anomaly.AnomalyResult]] = None, return_df: bool = False, sort_by: Optional[str] = None) -> Optional[pd.DataFrame]`**  
  Prints every detector's results and the recommended one.
- **`get_summary(models: Optional[List[multimodel_analysis.unsupervised.anomaly.AnomalyResult]] = None, save_prefix: Optional[str] = None, show_plot: bool = True)`**  
  Runs the full reporting pipeline: table, ranking chart and scatter plots.
- **`get_model(name: str) -> Any`**  
  Returns the FITTED estimator for ``name`` (display name, as shown in the report).
- **`get_labels(model: Optional[str] = None) -> np.ndarray`**  
  1 = anomaly, 0 = normal, for every row (default model: the best one).
- **`get_scores(model: Optional[str] = None) -> np.ndarray`**  
  Anomaly score of every row for ``model`` (default: the best one). Higher = stranger.
- **`assign_anomalies(model: Optional[str] = None) -> pd.DataFrame`**

  The ``n`` strangest rows (original values + score), strangest first.
- **`consensus(min_votes: Optional[int] = None, models: Optional[List[multimodel_analysis.unsupervised.anomaly.AnomalyResult]] = None) -> pd.DataFrame`**  
  Your data with a ``votes`` column (how many models flagged the row) and a ``consensus`` flag.

  Anomaly score of NEW rows (higher = stranger); compare with ``threshold`` of the model.

- **`predict(X: Any) -> np.ndarray`**  
  Predicts for new rows. Classification returns the ORIGINAL labels (strings stay strings).
- **`transform(X: Any) -> np.ndarray`**  
  Maps new rows to the new feature space (dimensionality-reduction models).
- **`predict_proba(X: Any) -> pd.DataFrame`**  
  Class probabilities as a DataFrame with one column per class (classification only).
