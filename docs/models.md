# Model reference

_Generated by `tools/build_api_docs.py` - do not edit by hand._

Use the **key** in `include=[...]`, `exclude=[...]`, `run_model('key')` and `tune_models(...)`. The display name is what appears in reports and what `get_model(...)`, `predict(model=...)` and `save_model(model=...)` expect.

* **Standard** models run by default with `run_all_models()`.
* **Extra** models run when you ask: `include='all'` or by key.
* **Needs** means an optional package (see the extras in the README); without it the model is skipped, never an error.
